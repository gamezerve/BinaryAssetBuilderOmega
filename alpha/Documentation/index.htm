Uprising Mod SDK Alpha — live repository workspace

Open alpha/EALAModStudio.exe, select your mod, edit alpha/mods/<name>/data/mod.xml and click Build Mod. The same SDK receives updated compiler tools after successful Release/x86 compiler builds. Editable mod sources are preserved.

Successful builds publish alpha/builtmods/<name>/<name>.big and mod_1.0.skudef, with build.json and last-build.log in that directory. No CFG counterpart is published. Failures preserve the previous successful output; an old package does not indicate a successful new build. Temporary backend files are removed after each build. No game installation or automatic launch occurs.

This limited candidate uses EA's existing Mod BuildStudio interface. Local user tests confirm sample build success, warning/error display, malformed-XML failure and this documentation pane. This is not full original-SDK feature parity.

A rejected build reports Error: ALPHA100 and Critical: ALPHA101, followed by an alpha build failed message. Successful builds report package paths and Build Completed. Inspect the final receipt; old packages from earlier builds are not new output.

Closing during a build

If this Studio still owns an active build, closing asks whether to cancel it. Yes stops its worker processes and releases the SDK lock before closing. No leaves Studio and the build running. Idle/completed builds do not prompt. Other sessions/processes are untouched. Last-good output is preserved; cancellation cannot interrupt final publication halfway through. The .sdk.lock file may remain normally after its operating-system lock is released. Restart an already-open Studio once to enable this update; earlier uncontained builds are not adopted.

Your mod and developer tests

Reborn belongs to the user. Automated developer tests do not modify or build it. RebornTest is the reusable developer slot. Previous sample mods are now regression fixtures outside this list.

Conscript: six editable scalars

Select RebornTest and click Build Mod. Its data/mod.xml contains the complete original-ID Conscript XML. The selected XML is compiled through Core, native ownership, metadata and reference/stream checks before a fresh BIG is published. This is not a cached BIG export.

Editable attributes: GameObject BuildTime (0.1–600), ObjectResourceInfo/BuildCost Amount (integer 0–100000), Body/ActiveBody MaxHealth (1–100000), VisionInfo VisionRange and ShroudClearingRange (1–5000), LocomotorSet Speed (1–500). Keep the rest of the supplied XML unchanged. RebornTest new-ID trial: time=2, cost=15, health=750, vision=400, shroud=700, speed=100.

Other edits, arbitrary GameObjects, mixed arbitrary assets and unreviewed new identities are not enabled. ALPHA005 reports this limitation. UprisingXmlRoot in uprising-alpha.paths must point to matching official Uprising XML. The earlier original-ID grouped scalar profile has qualitative user gameplay confirmation, not independent numeric measurements.

Other supported input profiles

The original Reborn sample uses Allied GUN=5000. Archived ArmorCannon uses CANNON=5000 and GUN=100. The archived CombinedArmor fixture contains Allied GUN=250 and Soviet GUN=5000 together. CombinedArmorStrong contains Allied and Soviet GUN=5000 together. Edit mods/<name>/data/mod.xml. One AlliedConYardArmor or SovietConYardArmor, or one of each together, is accepted per build. All thirteen Percent values and five optional root scalars (Default, DamageScalar, SideDamageScalar, RearDamageScalar, FlankedPenalty) accept canonical integers from 0 to 10000; omitted scalars default to 100. Keep the identity and thirteen ordered armor entries. Unsupported input fails; it is not silently skipped. Allied GUN 5000/CANNON 5000 and Soviet GUN 5000 have user-observed gameplay evidence. CombinedArmor has positive Soviet evidence; CombinedArmorStrong has positive Allied evidence. Allied GUN=250 is inconclusive. Soviet was not re-tested in that stronger revision; other edits remain experimental.

The single alpha build step validates XML, compiles through Core and creates a BIG/SKUDef package. Read build.json for the final receipt. Embedded backend paths describe removed intermediates, not live output locations.

The archived ConscriptAK47 fixture describes one complete SovietAntiInfantryInfantryAK47 weapon. Only Damage may change (integer 0..10000, optional .0); all other fields stay as supplied. The sample uses Damage=50. An earlier diagnostic package has user-observed increased damage; new builds remain experimental. Armor and weapon assets cannot share a build in this alpha.

Experimental armor source build

The archived ArmorSource fixture is a three-file Includes/Defines/inheritFrom example producing AlliedConYardArmor and RebornNewArmor; imported bases are not emitted. ALPHA004 warns that this package has no gameplay proof and new IDs need consuming GameObjects.

Armor-only source declarations accept 1..32 owner IDs, 0..64 unique non-ALL damage entries each, and unsigned finite percentages 0..10000 with optional decimals/%. Exact =$NAME fields, reviewed definition forms, local/imported inheritance, directly visible instance bases and Include-free definition-only all leaves are supported. The graph is confined to the mod data root (32 sources, 64 edges, 64 KiB/file, one MiB total). Child replacement by Damage, same-ID source shadowing, definition overrides, arbitrary expressions/all Includes, reference Includes and nonempty Tags are rejected. Read README.md for supported source forms. Old sample routes remain unchanged.

Not supported by this alpha

General GameObject edits beyond the six Conscript scalars, other asset types, mixed armor/weapon streams, models, textures, music, maps, LOD selection, STR processing, automatic installation and game launch are not build-enabled here.

Configuration and prerequisites

uprising-alpha.paths contains literal absolute paths: PowerShell7, Driver, StaticManifest, GlobalManifest, CompilerDirectory and UprisingXmlRoot. GlobalManifest is required for weapons/Conscript; UprisingXmlRoot is required for Conscript. Legacy armor configurations remain accepted. Update Driver and CompilerDirectory after relocation. PowerShell 7, x86 .NET 8, compatible .NET Framework 4 and unpacked Uprising stock streams are required. This is a repository-linked development SDK, not a standalone portable distribution.

No stock archive is replaced. The SKU is a mod fragment, not a replacement game SKU. Duplicate identities or unsupported input fail the whole build. New builds are not automatically gameplay-verified.

Local use only: EA components come from your own SDK. Public redistribution review is incomplete.
