Uprising Mod SDK Alpha — local candidate

This limited candidate uses EA's existing Mod BuildStudio interface. Local user tests confirm sample build success, warning/error display, malformed-XML failure and this documentation pane. This is not full original-SDK feature parity.

A rejected build reports Error: ALPHA100 and Critical: ALPHA101, followed by an alpha build failed message. Successful builds report package paths and Build Completed. Inspect the final receipt; old packages from earlier builds are not new output.

Supported build

Select Reborn (GUN 5000) or Armor250 (GUN 250). Edit mods/<name>/data/mod.xml. Only the GUN Percent of AlliedConYardArmor is editable, as an integer from 0 to 10000. Keep all thirteen ordered armor entries. Unsupported input fails; it is not silently skipped.

The single alpha build step validates XML, compiles through Core and creates a BIG/config/SKU package. Results are under builtmods/RebornAlphaInput-<guid>. Read alpha-build.json for the final build receipt.

Not supported by this alpha

Other asset identities/types, includes, inheritance, models, textures, music, maps, LOD selection, STR processing, automatic installation and game launch are not build-enabled here.

Configuration and prerequisites

uprising-alpha.paths contains four literal absolute paths: PowerShell7, Driver, StaticManifest and CompilerDirectory. Update Driver and CompilerDirectory after relocation. PowerShell 7, x86 .NET 8, compatible .NET Framework 4 and unpacked Uprising stock streams are required.

No stock archive is replaced. The SKU is a mod fragment, not a replacement game SKU. Only the earlier GUN-5000 package has user-observed gameplay evidence.

Local use only: EA components come from your own SDK. Public redistribution review is incomplete.
