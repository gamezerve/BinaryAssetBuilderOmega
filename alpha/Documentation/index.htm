Uprising Mod SDK Alpha — local candidate

This limited candidate uses EA's existing Mod BuildStudio interface. Local user tests confirm sample build success, warning/error display, malformed-XML failure and this documentation pane. This is not full original-SDK feature parity.

A rejected build reports Error: ALPHA100 and Critical: ALPHA101, followed by an alpha build failed message. Successful builds report package paths and Build Completed. Inspect the final receipt; old packages from earlier builds are not new output.

Supported build

Select Reborn (GUN 5000), Armor250 (GUN 250), ArmorCannon (CANNON 5000, GUN 100) or SovietArmor (Soviet GUN 5000). CombinedArmor contains Allied GUN=250 and Soviet GUN=5000 together. CombinedStrong contains Allied and Soviet GUN=5000 together. Edit mods/<name>/data/mod.xml. One AlliedConYardArmor or SovietConYardArmor, or one of each together, is accepted per build. All thirteen Percent values and five optional root scalars (Default, DamageScalar, SideDamageScalar, RearDamageScalar, FlankedPenalty) accept canonical integers from 0 to 10000; omitted scalars default to 100. Keep the identity and thirteen ordered armor entries. Unsupported input fails; it is not silently skipped. Allied GUN 5000/CANNON 5000 and Soviet GUN 5000 have user-observed gameplay evidence. CombinedArmor has positive Soviet evidence; CombinedStrong has positive Allied evidence. Allied GUN=250 is inconclusive. Soviet was not re-tested in CombinedStrong; other edits remain experimental.

The single alpha build step validates XML, compiles through Core and creates a BIG/config/SKU package. Results are under builtmods/RebornAlphaInput-<guid>. Read alpha-build.json for the final build receipt.

Select ConscriptAK47 for one complete SovietAntiInfantryInfantryAK47 weapon. Only Damage may change (integer 0..10000, optional .0); all other fields stay as supplied. The sample uses Damage=50. An earlier diagnostic package has user-observed increased damage; new builds remain experimental. Armor and weapon assets cannot share a build in this alpha.

Experimental armor source build

Select ArmorSource for a three-file Includes/Defines/inheritFrom example producing AlliedConYardArmor and RebornNewArmor; imported bases are not emitted. ALPHA004 warns that this package has no gameplay proof and new IDs need consuming GameObjects.

Armor-only source declarations accept 1..32 owner IDs, 0..64 unique non-ALL damage entries each, and unsigned finite percentages 0..10000 with optional decimals/%. Exact =$NAME fields, reviewed definition forms, local/imported inheritance, directly visible instance bases and Include-free definition-only all leaves are supported. The graph is confined to the mod data root (32 sources, 64 edges, 64 KiB/file, one MiB total). Child replacement by Damage, same-ID source shadowing, definition overrides, arbitrary expressions/all Includes, reference Includes and nonempty Tags are rejected. Read README.md for route selection and validation-only usage. Old sample routes remain unchanged.

Not supported by this alpha

Other asset types, mixed armor/weapon streams, models, textures, music, maps, LOD selection, STR processing, automatic installation and game launch are not build-enabled here.

Configuration and prerequisites

uprising-alpha.paths contains five literal absolute paths: PowerShell7, Driver, StaticManifest, GlobalManifest and CompilerDirectory. GlobalManifest is required for weapon builds; legacy four-key armor configurations remain accepted. Update Driver and CompilerDirectory after relocation. PowerShell 7, x86 .NET 8, compatible .NET Framework 4 and unpacked Uprising stock streams are required.

No stock archive is replaced. The SKU is a mod fragment, not a replacement game SKU. Duplicate identities or unsupported input fail the whole build. New builds are not automatically gameplay-verified.

Local use only: EA components come from your own SDK. Public redistribution review is incomplete.
