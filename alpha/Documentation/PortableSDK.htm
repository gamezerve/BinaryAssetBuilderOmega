Portable Uprising SDK alpha

Copy alpha to a writable location and open EALAModStudio.exe. Configuration follows the copied SDK. Building requires no repository checkout, separate PowerShell/.NET installation, unpacked D:/TEMP streams or .NET SDK.

Bundled dependencies

  • PowerShell 7 and its runtime: runtime/powershell.
  • 32-bit .NET 8 compiler runtime: runtime/dotnet-x86.
  • Native Visual C++ x86 audio dependencies: runtime/vc-x86.
  • Build scripts, compiler assemblies and internal schema resources: scripts and tools.
  • Stock streams, catalogs, WorldBuilder data and strings: catalogs/ra3ep1.
  • Original sources, schemas and editable content: SageXML, Schemas, Art, Audio and mods.
  • Legacy DirectX helpers for the optional shader tool: ShaderCompiler.

Windows requirements

This bundle targets 64-bit Windows 10/11 with 32-bit application support and .NET Framework 4.x/CLR4 for EA Studio. The tested host uses .NET Framework 4.8. GPU/Direct3D9 driver support is needed for optional shader graphics validation. Uprising itself is needed to play the compiled mod.

Results and copying

Final Streams/Misc BIG files and SKUDef still go to the current Windows user's Documents/Red Alert 3 Uprising/Mods/<mod> directory.

builtmods stores internal receipts; .work stores temporary data. Both folders may be omitted from a copy: startup creates them when missing and preserves existing contents. Copy while builds are stopped.

DATA:, ART: and AUDIO: paths follow the SDK. Explicit external paths in your own mod remain external. Separate launchers may need their settings updated.

The repository alpha receives compiler updates after successful builds. A separate copy is independent and receives updates by copying updated files. Synchronization preserves editable mods.

See PortableSDK.md for the complete record. Local portability does not establish public redistribution permission for EA components.
