## Independent contract

Option/profile: `--instance-metadata` /
`diagnostic-direct-instance-metadata-v1`. It composes the independently tested
upgrade/filter/bitflag/marker/choice/removal/chain/root-file scopes; all earlier
defaults and options remain unchanged.

Both the raw Include attributes and captured edge must say all; the physical
path must agree with the existing scoped resolver and confined captured source
inventory. Reference, missing/precompiled, forged, cyclic and duplicate/mixed-role
targets remain closed. A metadata leaf consumes one source edge and cannot
bypass the 32-edge depth/cache-height bounds. Existing 64 direct Include,
512 source, 4 MiB source and 32 MiB snapshot/prepared closure bounds remain.

`SdkMetadataDefinitions.Prove` requires unprefixed EA AssetDeclaration with only
namespace root attributes, at most 1024 descendant elements and one to three
unique metadata containers: Tags, Includes, Defines. Tags and Includes must be
empty of elements; container attributes, meaningful text, directives and unknown
metadata are refused. There must be 1–512 uniquely named definitions under the
existing name/value/override rules. Forward/missing names, overriding definitions,
duplicates and unsupported expression forms are refused.

Definition expressions are checked in declaration order using the existing
reviewed alias, quoted-suffix concatenation and checked integer multiply-add
subset. This proves the leaf's definition content, not substitution into the
owner. The original leaf bytes must pass full effective-schema binding and
return zero typed file fields. No asset declaration can pass this shape gate.

Metadata leaves are captured and schema-validated but never inserted into the
external asset-handle dictionary. Their bytes are unchanged; closure evidence
uses raw SHA-256 for both captured and unchanged processed identities. The
source-local Include witness is
`MetadataDefinitionIncludes(SourcePath, RawSha256, Definitions, AssetExports=0)`.
Inherited parents retain source closure evidence but do not replay a child's
metadata Include event as their own. Failure publishes no partial source,
