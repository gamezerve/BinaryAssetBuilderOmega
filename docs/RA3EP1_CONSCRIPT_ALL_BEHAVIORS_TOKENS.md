# All 36 original Conscript behavior metadata graphs

## Outcome — October 17, 2026

All 36 complete original behavior leaves, covering 24 concrete families, pass
independent stock metadata comparison: **16,608 bytes of leaf metadata**.
This follows the complete native gate; it does not replace it with reduced or
silently skipped records. Each leaf is compiled through real Core normalization,
semantic dependency resolution and native dispatch. The shared native proof still
uses one Core table / 21 strong occurrences / one Tracker, now with corrected
BIN/RELO/IMP sizes **5,620 / 388 / 88 bytes**.

This milestone proves individual leaf metadata. It does **not** compose the
36-leaf Behaviors metadata container, integrate all 49 original module owners,
publish a complete GameObject, broaden SDK alpha admission or prove new gameplay.

## Production generator and independent oracle

`Ep1BehaviorMetadataTokenizer.Tokenize` accepts only a bounded native Chunk,
compiled schemas, an explicitly reviewed wire family and its native CLR type.
It never receives stock bytes, offsets, reference indices or per-asset tables.
The separate existing EP1 hardpoint-only WeaponSet writer remains in use; empty
turret/hierarchical/contained lists are checked, not approximated as hardpoints.

For the other families the generator derives own attributes then sequence
members from schemas, inherited tables from schema/native bases, and storage
from actual CLR layout. It checks disjoint native allocation owners, bounded
pointer/list/string traversal, complete native coverage, zero padding and exact
auxiliary ownership. Unknown particles, native members and wire signatures fail
closed. Output native pointers and auxiliary slots shift exactly once; imports
keep their actual Core occurrence values.

Field type signatures are **not plain hashes of XSD type names**. A separately
reviewed literal signature catalog is embedded in the generator, with no asset
offsets or payloads. Declaration-level reference identity matters: for example,
`Poid:ModuleData` is `BDF07965`, while `Poid:ObjectFilter` is `4D3B3F19`.
Repeated types have explicit keys; not all repeated signatures differ from their
scalar counterpart. `BehaviorMetadataTypeReview` independently inventories the
observed bounded stock signatures and rejects inconsistent observations. Its
diagnostic output is never fed to the production generator at runtime.

`BehaviorMetadataStockProof` compares every generated row name, type tag and
internal table target literally to the admitted stock prefix. Native targets
are checked using separately walked native **field paths**, not one global
stock-address map: two logical fields can share stock storage yet require two
different generated allocations. The existing strict coordinate-map behavior
of older gates stays unchanged. The proof also reconstructs the complete shifted
native tail and auxiliary arrays independently.

All input official source files remain read-only and are hash-bracketed through
authored controls and shared-native verification. The source preparation limits
from the native gate remain: explicit three-object chain, stable SlowDeath child
family grouping and one captured GlobalDefines scaler. This is not a general
inheritance/include engine.

## Two additional ABI corrections exposed by metadata

| Family | EP1 native model | Why the earlier native-only test could pass |
| --- | --- | --- |
| CreateObjectDie | 72 bytes; CreationList at 52, UpgradeRequired header at 56, UpgradeForbidden at 64 | KW's extra 8-byte DebrisPortionOfSelf header put the two empty list headers at 64/72; empty headers could compare equal while metadata targets named different owners |
| FireWeaponWhenDeadBehavior | 148 bytes; existing flags at 140..142, FireAtGround at 143, UseMyKillerAsWeaponSource at 144 | The original false/default flags were unmodeled or padding in the legacy 144-byte model |

Both corrections use new EP1 structs and explicit allocation in
`Marshaler.MarshalEp1InfantryBehavior`, retaining original wire IDs `3B68B768`
and `90CEB49C`. The legacy KW structs/marshalers are unchanged. The earlier
native-only milestone's 5,624-byte shared allocation is historical; this gate
strengthens its evidence rather than treating the old empty fields as proof of
their full ABI.

Fourteen authored/refusal controls cover the existing four isolated records,
the two new record sizes, absent KW debris attribute, new true/default flags and
their literal metadata target offsets. One additional authored reference control
uses two distinct real UpgradeTemplate names through Core, then checks both
populated creation-list headers, imported identities and metadata count targets.
No authored numeric compiler occurrence indices are used.

## Refusal and regression coverage

Every leaf repeats deterministically without mutating its native input.
**250 metadata/input refusals** cover wrapper/name/tag/table corruption, native
tail mutation, missing nonempty output RELO/IMP, invalid input wire identity and
orphan input storage. **142 native corruption refusals** and nine shared/native
dependency controls also remain active. These counts do not claim exhaustive
support for optional graphs absent from the selected original leaves.

Discovery: `conscript-behavior-token-survey <official-xml-root> <static.manifest> <global.manifest>`.
Strict gate: `conscript-behavior-token-self-test` with the same arguments.
The strict command requires 36/36 native and metadata rows; blocked discovery
rows cannot make the regression green. The Focused batch adds the strict gate
when `-UprisingXmlRoot` is explicitly supplied.

Final Focused batch with explicit official XML root: **67/67 groups passed** in
**231.180 seconds**, with the strict metadata group at **6.959 seconds** and
native group at **7.344 seconds**. All eight runtime hashes stayed unchanged;
the batch compiler build passed in 1.24 seconds with zero warnings/errors.
Earlier changed-dependency builds retained two pre-existing audio nullable
warnings. No Full-profile run, game launch or installation mutation occurred;
the SDK alpha capabilities remain unchanged. Elapsed time is evidence for this
run, not a controlled performance comparison.

Evidence: `artifacts/ConscriptAll36BehaviorTokens-a/batch-report.json`,
`compiler-build.log`, `conscript-behavior-native.log` and
`conscript-behavior-tokens.log`. The strict metadata JSON reports 36 native /
36 metadata verified / zero blocked rows, the 250 refusals and all authored
controls, plus `GameObjectPublicationEnabled=false`.
