## Source, schema and ABI qualification

`GameObjectEmptyRootSmokeTest.cs` independently binds all sixteen native slots
to the existing 600-byte CLR GameObject and checks pointer versus inline-list
storage. The captured stock root has zero storage in all 21 relevant words
(five count/items headers and eleven pointers). Empty list metadata is not a
zero target: each real stock count-marker table points to that list's native
count word. Null pointer fields instead have a literal zero metadata target.

The admitted official schema must retain Browser as an optional StringList
attribute and each other name as an optional direct root element with its
reviewed type and repeated/singleton category. Field defaults/fixed values must
not implicitly introduce populated children. Exact stock root names/type tags
are checked independently, not inferred from CLR class presence.

All three captured original root sources and the selected source pass the
source admission guard before normalization/allocation in this explicit route.
None of the fifteen child elements is present; Browser is absent or empty.
The AudioArraySound example in the concrete unit XML is inside an XML comment
and is not an active child. An authored empty Browser attribute also passes
official schema validation. Source guards are intentionally conservative:
even a present empty child is refused until its specific present-child semantics
are reviewed; a nonempty Browser is refused too. This prevents unsupported
source from silently disappearing into zero native storage.

## Separate production opt-in

`Ep1GameObjectEmptyRootProjection.ValidateSource` is the explicit source guard.
`Compose(native, schemas)` requires all 21 native words to be zero, then reuses
the qualified 110-field owner composer and its full native ownership checks.
It inserts sixteen named root rows, emits five count-marker tables and leaves
eleven targets null. Existing metadata addresses, native pointer words and
auxiliary source positions are translated to the enlarged native origin;
occurrence indices and all other native values remain unchanged.

The producer accepts no stock tables, per-asset coordinates or diagnostic survey
facts. The sixteen literal wire signatures are independently observed type
identities. Legacy/default producers and the previous 104/110-field profiles
remain separate and unchanged. This does not expand exported alpha admission.

## Independent verification and refusals

The actual emitted root key/type set must exactly equal stock's 126 names/tags.
Each of the five emitted empty list tables is compared to the stock marker and
its independently checked native offset. All eleven absent targets must remain
zero. The whole transformed native tail and exact ordered RELO/IMP are inverted
against the original shared graph; repeated output is identical and input
buffers are unchanged.

The test detaches the **actual existing 110-field metadata** from this output
and checks it with the prior six-owner/49-module oracle. It does not invoke a
producer to manufacture expected observed metadata. This rechecks all populated
owner semantics and all 49 complete module graphs in their common occurrence
context, rather than proving only the new zero fields.

**102 refusal controls** cover every nonzero native count/items/pointer word,
each root row's name/type/target, all fifteen list-marker words, unsupported
source forms and removed auxiliary streams. An optional empty Browser source
is separately validated as a positive control. Existing six-owner and all-module
controls remain in their own regression routes.
