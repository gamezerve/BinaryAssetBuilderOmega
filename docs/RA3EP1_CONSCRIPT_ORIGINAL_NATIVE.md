Pointers are compared through their owned records and reference indices through
their semantic type/instance identities, not by raw addresses or captured index

explicit and bounded; no other string, numeric field, byte flag or weak ID is

## Explicit original source assembly

`GameObjectOriginalNativeSmokeTest.cs` replaces every synthetic root attribute
and non-module child with captured BaseObject -> BaseInfantry ->
SovietAntiInfantryInfantry data. The already qualified complete original module
sources are retained, including their earlier explicitly documented particle
grouping, render-name resolution and chooser-default preparation. The enclosing
gate hash-brackets all three object sources and GlobalDefines read-only.

Root attributes use the explicit child-over-parent values for this captured
chain. ArmorSet is additive (two inherited sets plus the concrete set); the
concrete LocomotorSet is retained. Direct singleton children use the last
captured occurrence. Independent whole-native stock equality qualifies this
specific assembly; it is **not a general implementation** of EA's inheritance,
include or instance-expression engine.

The two remaining root definitions use their captured literal values:
`ACCOUNT_ORE=0` and `STANDARD_SHROUD_CLEAR=500.0`. Unreviewed residual attribute
expressions refuse. The concrete DisplayName's one `xai:joinAction="Replace"`
is consumed by explicit concrete-child selection before schema validation;
all other instance directives refuse rather than being broadly stripped.
Only direct root children are ordered by the admitted official root particle.

Examples of actual retained values include BuildTime=4, three real ArmorSets,
the NORMAL human locomotor at speed 50, the original cylinder geometry, the
concrete display/localization text and icon/intro targets. Concrete subgroup
priority=505 and inherited under-fire timeout=10s/scan range=600 remain explicit overrides,
not replaced with generic defaults. Every strong target must resolve uniquely
in the actual stock catalogs before one Core normalization and allocation.

## Independent whole-native proof

`SelectedNativeGraphComparer.CompareRootSelection` walks the complete typed root
and its ordinary root-owned allocations with explicit module/EP1-owner pointers
temporarily detached in **owned comparison copies** of both native graphs.
It returns exact visited byte/auxiliary ownership, not a false claim that
untouched heap bytes were verified. Its empty polymorphic-header path is scoped
only to this entry point; ordinary full comparisons retain their old admission.

The enclosing gate independently restores/checks every detached parent,
container count/item array and original concrete class identity. Complete
concrete module, six-owner and geometry graphs use their already reviewed native
types, including isolated EP1 layouts. Each leaf independently checks all fields,
its full auxiliary ownership and semantic references. Their disjoint coverage
and relocation/import sets are then unioned with root coverage. The final union
must equal all supplied auxiliary slots, consume exactly 1..275 Core occurrences
once and cover the complete native graph, allowing only bounded zero alignment
padding. Cross-owner pointers, duplicate owners and hidden allocations refuse.

The 108 controls cover mutation of every flat root descriptor, thirteen parent
pointer removals, absent RELO/IMP, trailing orphan bytes, a real BuildTime source
edit that must differ from stock and an unresolved icon source. Repeated actual
source builds are byte-identical. Existing selected-root/module/metadata controls
remain separate regressions; native success does not substitute for metadata.
