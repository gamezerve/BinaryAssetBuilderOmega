## Source and independent proof

`ConscriptRemainingRoots.cs` captures BaseObject, BaseInfantry,
SovietAntiInfantryInfantry and GlobalDefines read-only and hash-brackets them.
The explicit last direct child across this three-object chain selects each
owner. The captured `ACCOUNT_ORE=0` definition is substituted for the original
BuildCost; this is not a newly claimed general expression/inheritance engine.

The effective official schema validates the source envelope. Schema-derived
strong references resolve to unique real stock targets before Core normalization.
Nine voice sounds, thirteen EVA references and one shadow texture account for
all 23 occurrences. Each import is consumed exactly once. Six parent relocation
slots are checked, and extracted owner graphs cannot point into another owner.

Production `Ep1BehaviorMetadataTokenizer.TokenizeRootRecord` accepts reviewed
native/schema inputs, not stock tables, addresses or diagnostic type discoveries.
Independent stock comparison checks field signatures/targets, repeated records,
native values, semantic identities and the exact transformed native tail and
RELO/IMP. Repeated output is deterministic and input chunks stay unchanged.
The observed type report is diagnostic only, never a production catalog input.

## Concrete KW/EP1 differences

- EP1 skirmish AI occupies 92 bytes, versus the old 20-byte model. The isolated
  `Ep1SkirmishAIInformation` retains official scalar defaults, masks, optional
  scalar/status pointers and six flags at independently checked offsets.
- CrusherInfo remains 52 bytes but its internal order differs: the EP1 default
  kill delay is at offset 20 and extra-list headers are at 24 and 32. The isolated
  `Ep1CrusherInfo` avoids silently reusing the incompatible KW ordering.
- Root EVA is an ordered list of 8-byte strong-reference/enum entries, not KW's
  fixed pointer fields. `Ep1EvaEventArray` retains thirteen original entries;
  its 30 literal enum ordinals are checked against the schema and authored cases.
- The existing EP1 voice graph has an empty EVA handle in each SoundOrEvaEvent.
  Its metadata targets the zero handle word, not a missing string allocation.
  Nonempty voice EVA handles remain refused until that separate ABI is reviewed.
- Pipeline-only CrusherInfo ID metadata is not emitted as a native field.

Legacy root layouts and default dispatch remain unchanged. The new public
marshal overloads and six-record metadata route are explicit, bounded opt-ins.

## Controls and deliberate limits

EVA list, optional skirmish values/status/resource edits, crusher timing/signed
level/flag edits, a two-account resource cost list, shadow edits and eight
unreviewed/invalid input refusals. Authored metadata is generated repeatedly and
its native tail is checked; arbitrary authored variants are not claimed to have
independent stock exemplars. Separately, stock comparison rejects **18 native**
and **30 metadata** corruptions, including missing nonempty auxiliary buffers.

Populated skirmish contextual powers, base-selection criteria, DodgeWithUnits
and optional defending-mask storage remain closed. Both nonempty crusher extra
lists remain closed. Empty placeholder headers do not establish their item ABI.
No generic includes/inheritance/definitions closure is inferred from this test.
